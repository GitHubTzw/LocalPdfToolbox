本地工具箱 V2 · PDF 整理 + 本地开发工具

启动：双击同目录的 LocalPdfV2.exe。
如果从源代码项目启动，双击项目根目录的“启动工具箱.cmd”。

窗口顶部是五个页签，全部功能都在本机进程内完成，不联网、不上传、不写使用历史。

【页签 1：PDF 工作台】
- 点击“添加 PDF”，或把 PDF 直接拖进窗口；也可以拖到其他页签上，会自动切回本页签。
- 页面列表支持拖拽排序：按住某一行上下拖动即可调整顺序，列表顺序就是导出顺序。
- 行内悬浮按钮：鼠标移到某一行（或选中该行）会出现上移、下移、左转、右转、复制、删除。
- 双击任意一行，直接打开该页的内容编辑窗口，改完保存回工作区。
- 顶部按钮：全选/反选、编辑内容、旋转、复制、删除、撤销（最多 30 步）。
- 输入 1-3,5 并点“按页码选中”，再点“仅保留选中”，可提取指定页。
- 右侧是页面预览，双击预览图可放大。点“导出新 PDF”保存为新文件。
- 快捷键：Ctrl+A 全选、Ctrl+Z 撤销、Delete 删除选中页。
- 左侧来源面板底部有“PDF 工具”区：
  · 文档信息：查看页数、每页尺寸（点）和文件大小。
  · 提取文字：把文字层另存为新的 TXT 文件（按页加“===== 第 N 页 =====”分隔）。
  · 拆分 PDF…：可选“每 N 页拆成一个文件”，或“按页码范围拆”（如 1-3;4-6;7，支持中文逗号）。
    结果全部另存为新文件，文件名自动加页码标签，绝不覆盖已有文件。

【页签 2：JSON / XML】
- 格式化、压缩（去掉多余空白）、校验（无效时给出行列位置）。
- 转义 / 去转义：把文本转成 JSON 字符串转义形式，或还原回来。
- 格式互转：转 XML、转 JSON、转 CSV（对象数组转表格）、CSV 转 JSON。
- 结构工具：统计结构（节点总数、最大深度、类型分布）、数组去重、数组排序。
- 路径提取：按 data.items[0].name 这样的路径取值，支持 * 通配和负下标。
- 模型生成：按 JSON 结构生成 C# / TypeScript / Java / Python / Go / SQL 类型定义；
  C# 按 CRTVUP 风格生成块级命名空间、Model 后缀和逐成员注释，属性名不一致时自动加 JsonPropertyName。
- 支持 2 空格 / 4 空格 / Tab 缩进，可勾选“按属性名排序”。
- XML 禁止 DTD 和外部实体，不会读取本机文件或访问网络。

【页签 3：编码转换】
- 左侧“转换方式”列表共 33 项，选中后下方参数条会自动显示该方式需要的输入。
- 编解码：Base64、Base64URL、Base32、URL、Unicode、HTML、十六进制的编码与解码。
- 文本哈希：MD5 / SHA-1 / SHA-256 / SHA-512；可对文件计算摘要。
- HMAC 签名：用同一套哈希算法和密钥对文本签名。
- AES 加解密：AES-256-GCM + PBKDF2-SHA256，密文以 LPDF1: 开头，口令不落盘。
- JWT 解析：只解码头部和载荷，不校验签名，也不代表令牌有效。
- GUID 生成：一次最多 500 个，可选大写、花括号、无连字符。
- 进制转换：2 / 8 / 10 / 16 进制互转，支持 0x / 0b / 0o 前缀、下划线和负数。
- 颜色转换：HEX / RGB / HSL 互转，并给出亮度建议。
- URL 拆解：拆出协议、主机、端口、路径、查询参数；只做字符串分析，不会访问该地址。
- 命名风格转换：camel / pascal / snake / kebab / constant / upper / lower / title。
- 正则测试：填表达式和选项（i 忽略大小写 / m 多行 / s 单行），列出匹配位置和捕获组；有 2 秒超时保护。
- 文本统计：字符数、UTF-8 字节数、行数、非空行数、词数、中文字符数、空白字符数、最长行长度。
- 行操作：行排序、行去重（可忽略大小写）、行反转、删除空行、加行号。
- 时间戳互转：秒或毫秒时间戳 ↔ 本地时间，另有“现在的时间戳”。
- 字符集可选 UTF-8 / GBK / UTF-16 LE / UTF-16 BE / ASCII / Latin-1。
- 勾选“自动转换”后边输入边出结果；文件 → Base64、Base64 → 新文件都只读写本地文件。

【页签 4：文件对比】
- 顶部“对比模式”可选文本对比 / 二进制对比 / 目录对比。
- 文本对比：左右并排逐行对比，新增 / 删除 / 修改用不同底色标出；
  勾选“行内差异高亮”后，修改行里本侧独有的词会再单独标色；底部显示相似度。
- 忽略规则：忽略大小写、忽略空白、忽略空行、忽略行尾空白、忽略注释行；可勾选“只显示差异行”。
- 二进制对比：按字节比较两个本地文件，报告是否一致、首个不同位置和两侧大小。
- 目录对比：递归比较两个文件夹，可只比文件大小（更快）或按 SHA256 内容摘要比较；
  会跳过符号链接、目录联接和云文件占位符，两侧选同一个文件夹会被拒绝。
- 导出报告：把当前对比结果另存为 TXT 或 Markdown 表格。
- 文本对比单侧最多 20000 行，目录对比单侧最多 20000 个文件；差异过多时中间部分按整块差异显示，并在状态栏说明。

【页签 5：文件压缩（把体积压小，不是打包成 ZIP）】
- 支持 PDF、图片（PNG/JPEG/BMP/TIFF）和 Office 文档（DOCX/XLSX/PPTX）。
- 步骤：点“添加文件” → 选压缩强度 → 点“选择输出文件夹” → 点“开始压缩”。
- 压缩强度：轻度（质量 85）、标准（质量 70）、强力（质量 55 + 缩放到 75%）、极限（质量 40 + 缩放到 50%）。
- PDF：默认无损重写文件结构，压缩内部流并去掉冗余，保留文字和图形；勾选“PDF 转成图片版”后
  每页渲染成 JPEG 再重建，体积最小，但会丢失可搜索文字层，请按需选择。
- 图片：按质量重新编码，可缩小分辨率；BMP 会转成更小的 PNG；多帧 TIFF 保留全部帧。
- Office 文档：按最大压缩率重新打包内部 ZIP，只搬运原有条目，不改写内容，不执行宏或公式。
- 结果保存到指定文件夹，文件名自动加“-压缩”后缀；同名文件不会被覆盖。
- 列表会显示每个文件的原始大小、压缩后大小和变化百分比；体积没有变小时会提示保留原文件。
- 下方“打包与解压（ZIP / GZip）”是折叠区，保留原来的 ZIP 打包、解压、GZip 压缩解压和查看 ZIP 内容。
- 解压 ZIP 时会拒绝越界条目、设备名和覆盖已有文件。

注意：
- 所有处理都在本机内存和本地磁盘完成；不调用网络接口、AI、统计或更新服务，不启动 Office 或外部转换程序。
- PDFium/PdfPig 是随附的本地代码库；Office 使用本地 ZIP/XML 解析，不执行宏、脚本、公式或外部资源。
- 不添加水印，不修改源文件，也不会覆盖已有同名文件；导出只新建文件。
- 清空或关闭后不保存本次文件列表、操作记录或预览缓存。
- 请选择未被 OneDrive、网盘、备份软件自动同步的本地文件夹。
- 网络路径、映射网络盘、符号链接和云占位文件会被拒绝。
- PDF 部分处理普通页面；带密码、数字签名、表单、批注等特殊文件会提示无法处理，以避免丢失内容。
- 输出不复制原文档的可点击链接、书签、附件及文档级属性。页面文字、图形和原有印刷水印仍会保留。
- 对象删除不是彻底脱敏工具；其他对象、共享资源或不可见内容不保证被删除。
- PDF 最多 5000 页；格式转换一次最多 500 页；文字最多 500 节、200 万字符。
- Windows 自身的缓存、交换文件、崩溃转储及其他软件的同步不由本工具控制。

运行环境：Windows x64；文件夹已随附 .NET 10 Desktop Runtime（x64），无需单独安装。
移动程序时请复制整个目录，包括 runtime、licenses 及 DLL，不能只复制 LocalPdfV2.exe。
EXE 使用原创 PDF 图标，不需要联网取得图标或字体。

V1 版“本地 PDF 工作台”仍在 dist\LocalPdf 中独立可用。
