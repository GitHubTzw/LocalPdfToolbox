# 本地 PDF 工作台

Windows x64 桌面应用：PDF 内容编辑、页面整理、图片及 Office 文字转换。使用 .NET 10 / WPF，文档解析、编辑、渲染和转换都在本机进程内完成。

## 两个版本

| 版本 | 位置 | 说明 |
|---|---|---|
| V1 本地 PDF 工作台 | `dist/LocalPdf/LocalPdf.exe` | 原有界面保持不变，专注 PDF 整理、内容编辑和格式转换 |
| V2 本地工具箱 | `dist/LocalPdfV2/LocalPdfV2.exe` | 重做 PDF 页面操作，并新增 JSON、编码、对比、压缩四个页签 |

V1 与 V2 是同一个解决方案里的两个独立程序，互不影响：V2 复用 V1 的内容编辑与格式转换窗口，但拥有自己的主界面和页签布局。两者的本地处理规则、路径策略和“不覆盖源文件”约束完全一致。

## 直接使用

进入 **`dist/LocalPdf` 文件夹，双击 `LocalPdf.exe`**。应用、原创 PDF 图标、本地解析库、许可和 .NET 10 桌面运行库均在这个文件夹内，无需安装 Office、PDFgear 或单独安装 .NET，无需联网。

也可双击项目根目录的 **启动工具.cmd** 或 **打开本地PDF工作台.lnk**。移动到其他 Windows x64 电脑时，复制整个 `dist/LocalPdf` 文件夹，不能只复制 EXE；不要删除其中的 `runtime` 目录。旧的其他部署副本不会自动更新。

| 操作 | 用法 |
|---|---|
| 合并 | 添加多个 PDF，调整页面列表，点击“合并并导出 PDF” |
| 调整顺序 | 勾选一页或多页，点击“上移”“下移” |
| 选择页码 | 输入 `1-3,5`，点击“按页码选中”；页码按当前输出列表计算 |
| 提取页面 | 选中页面后点“仅保留选中”，再导出 |
| 删除 / 旋转 | 勾选后点“删除”或“旋转 90°” |
| 预览 | 单击页面；双击右侧预览可放大 |
| 编辑 PDF 内容 | 只选一页，点击“编辑内容”，选择文字、图片或图形后修改；保存到工作区，再导出新 PDF |
| 添加内容 | 支持插入文字/图片、拖动添加高亮和矩形边框；可撤销本次内容修改 |
| PDF 格式转换 | 点击“格式转换”，按当前页面顺序导出图片、TXT、Word、Excel 或 PowerPoint |
| 编辑 Office / TXT 文字 | “格式转换”→“图片 / 文字转 PDF”→选择 Office / TXT；读取文字后按分节编辑，另存 TXT/DOCX/XLSX 或生成 PDF |
| 图片转 PDF | 选择 PNG/JPEG/BMP/TIFF，支持多图和多页 TIFF；转换后加入工作区 |
| 撤销 | 点击“撤销”或 Ctrl+Z，最多 20 步；新增或移除源文档会重置撤销记录 |
| 结束 | 清空工作区或关闭窗口 |

始终选择新的输出文件名；已有文件和源文件都不会被覆盖。编辑原 PDF 页会更新此页在工作区的所有引用，保存到工作区后还需导出新文件。

## 本地工具箱（V2）

进入 **`dist/LocalPdfV2` 文件夹，双击 `LocalPdfV2.exe`**，或双击项目根目录的 **启动工具箱.cmd**。窗口顶部是五个页签，全部功能都在本机进程内完成。

| 页签 | 功能 |
|---|---|
| PDF 工作台 | 重做后的页面操作：拖拽排序、行内悬浮按钮、双击直接编辑内容、撤销 30 步、缩略图懒加载；另有文档信息、提取文字层、按页数或页码范围拆分 PDF |
| JSON / XML | 格式化、压缩、校验（给出行列）、转义/去转义；JSON↔XML↔CSV 互转、取值路径查询（支持 `*` 通配与负下标）、结构统计、数组去重/排序；按 JSON 生成 C# / TypeScript / Java / Python / Go / SQL 模型 |
| 编码转换 | Base64 / Base64URL / Base32 / URL / Unicode / HTML / 十六进制编解码、MD5/SHA 文本与文件哈希、HMAC 签名、AES-256-GCM 加解密、JWT 解析、GUID 批量生成、2/8/10/16 进制互转、颜色互转、URL 拆解、命名风格转换、正则测试、文本统计、行排序/去重/反转/删空行/加行号、时间戳互转，6 种字符集 |
| 文件对比 | Beyond Compare 风格的文本并排逐行对比（忽略大小写/空白/空行/行尾空白/注释行、行内差异高亮、只看差异行、相似度）、二进制字节对比，以及目录递归对比（只比大小或按 SHA256 内容摘要）；可导出 Markdown 对比报告 |
| 文件压缩 | 把文件体积压小（类似 WPS 的文件压缩）：PDF 重写结构或转图片版、图片按质量重新编码、Office 文档重新打包；输出只新建文件 |

PDF 工作台的操作方式：

| 操作 | 用法 |
|---|---|
| 导入 | 点“添加 PDF”，或把文件拖到窗口任意位置（会自动切回本页签） |
| 排序 | 按住页面行上下拖动；行内还会出现上移/下移/左转/右转/复制/删除按钮 |
| 编辑内容 | 双击页面行，或选中一页后点“编辑内容” |
| 多选与提取 | Ctrl / Shift 多选，或输入 `1-3,5` 按页码选中，再点“仅保留选中” |
| 文档信息 / 提取文字 | 左侧来源面板底部点“文档信息”看页数、每页尺寸和文件大小；点“提取文字”把文字层另存为新的 TXT |
| 拆分 PDF | 左侧来源面板底部点“拆分 PDF…”，可选“每 N 页拆成一个文件”或“按页码范围拆”（如 `1-3;4-6;7`），结果全部另存为新文件 |
| 撤销 | 点“撤销”或 Ctrl+Z，最多 30 步 |
| 快捷键 | Ctrl+A 全选、Ctrl+Z 撤销、Delete 删除选中页 |

工具箱的额外边界：

- 文本对比单侧最多 20000 行；差异过多时中间部分按整块差异显示，并在状态栏说明。
- 目录对比会跳过符号链接、目录联接和云文件占位符，单侧最多 20000 个文件；两侧选同一个文件夹会被拒绝。
- 体积压缩按文件逐个处理：PDF 默认无损重写结构（保留文字和图形），勾选“PDF 转成图片版”后体积最小但会丢失文字层；图片按质量重新编码并可缩小分辨率；DOCX/XLSX/PPTX 只重新打包内部 ZIP，不改写文档内容。
- 压缩结果保存到指定文件夹，文件名自动加“-压缩”后缀；同名文件不会被覆盖，体积没有变小时会如实提示保留原文件。
- 同一页签下方折叠区保留 ZIP / GZip 打包解压：解压时先选压缩包，再选上级文件夹，程序在其下新建不重名的文件夹；越界条目、设备名和覆盖已有文件都会被拒绝。
- 模型生成支持 C#（块级命名空间、`Model` 后缀、逐成员注释）、TypeScript、Java、Python、Go、SQL；字段名按目标语言的命名习惯转换。
- AES 加解密使用 AES-256-GCM + PBKDF2-SHA256（210000 次迭代），密文以 `LPDF1:` 开头，口令不落盘；JWT 只解码不校验签名，也不代表令牌有效。
- URL 拆解只是字符串分析，不会访问该地址；正则测试有 2 秒超时和匹配数量上限，避免卡死界面。
- 生成模型类、格式化 JSON/XML、编码转换都只处理输入框内容；XML 禁止 DTD 与外部实体。
- 不提供联网的在线接口、云端转换或 AI 功能；bejson 一类网站上的在线功能不会以任何形式被调用。

## 本地处理与数据边界

- 应用无服务端、HTTP 请求、网络端口、账号、遥测、自动更新、网页控件、外部字体或在线 AI。
- 源文件读入内存。随附的 PDFium/PdfPig 是本地代码库，用于解析、编辑、渲染与页面重组；不调用第三方网络接口，不启动 Office、命令行转换器、浏览器或其他外部处理程序。
- Office 格式只用本地 ZIP/XML 代码读写，图片由 Windows 内置编码器处理。XML 禁止外部实体；不执行宏、公式、PDF 脚本、表单动作或链接跳转，不读取外部资源。XML 中的命名空间网址只是格式标识，不会被访问。
- 预览不写图片缓存，程序不写日志、历史文件或会话数据库；原生文件对话框显式设置 `AddToRecent=false`。
- 新 PDF 先在内存构建，再使用 `FileMode.CreateNew` 写入用户指定的位置。写入失败或取消时，仅尝试清理本次未完成的新文件。
- 拒绝 UNC、网址、设备路径、备用数据流、网络映射盘、符号链接、目录联接和云文件占位符。
- 移除、清空和退出时释放预览句柄，并尽力清零持有的源字节数组。托管库内部副本、系统交换文件、Windows 缓存及崩溃转储无法保证全部擦除。
- 请使用不会被网盘或备份程序自动同步的本地目录。工具本身不上传，但无法控制其他软件或 Windows 自身的网络活动。

“不添加水印”指不生成新水印；源 PDF 已有的印刷水印属于页面内容，会照常保留。

## 格式与内容支持范围

| 输入 → 输出 | 实际效果 |
|---|---|
| PDF → PNG / JPEG | 每页一张图，支持 96/150/200 DPI；多页打包为 ZIP |
| PDF → TXT / DOCX 文字版 | 提取现有文字层，可继续编辑；不还原复杂版式 |
| PDF → DOCX 图片版 / PPTX 图片版 | 保留页面外观，文字成为页面图片的一部分 |
| PDF → XLSX 文字行版 | 每页一个工作表、每行一个文字单元格；不识别表格结构 |
| PNG / JPEG / BMP / TIFF → PDF | 图片保持比例，支持多页 TIFF |
| DOCX / XLSX / PPTX / TXT → PDF、TXT、DOCX、XLSX | 读取文字或已保存的单元格值，先编辑后转换；不保留图片、图表、原排版或数字格式，不计算公式 |

仅提供无需网络与外部处理程序的功能。扫描件 OCR、旧版 DOC/XLS/PPT、带宏格式、复杂 Office 排版还原、完整电子签章和云端 AI 不在本版本范围内。PPTX 目前输出为页面图片版；不能把扫描文字或图片版幻灯片自动变成可编辑文字。

适用于自包含的普通 PDF 页面，保留可搜索文字、字体和图形，不通过截图方式重新生成整页。

- 加密 PDF、交互表单、数字签名、非链接批注/印章、可切换图层及不支持的页面附加结构会明确拒绝，避免静默丢失内容。
- 输出不保留可点击链接、原书签、文档级元数据、附件和文档级脚本；部分特殊页面结构会拒绝导入。
- 内容编辑支持普通页面顶层文字、图片和图形；复杂裁剪、透明效果、嵌套组合等不能可靠修改时会明确拒绝。替换文字使用本机字体并嵌入 PDF，不承诺匹配原字体，也不自动重排周围段落。
- 删除对象不是彻底脱敏工具；原文档其他对象、共享资源或不可见内容不保证被删除。不会自动去除源文件已有水印。
- 不再限制单文件或会话大小，最多 5000 页。复杂文件实际占用内存可能高于其磁盘大小；原生解析器异常时仍可能需要重新启动。
- 格式转换一次最多 500 页；文字导入/编辑最多 500 个分节和 200 万字符。图片有像素上限，过大时需降低 DPI 或拆分处理。

## 离线构建与验证

```powershell
./build.ps1
```

构建脚本关闭 .NET CLI 遥测、工作负载更新提示和 NuGet 在线吊销检查，`NuGet.Config` 清空所有远端源，仅从 `vendor/nuget` 恢复包。缺少 SDK 或包时直接报错，不自动下载。发布时从构建机已有的匹配 .NET 10 核心及桌面运行库复制本地文件，并保留许可；EXE 配置为只查找随附的 `runtime` 目录。

构建包含：

- 控制台合成 PDF 测试：顺序、重复页、旋转、输入边界、源文件哈希不变、覆盖保护、内存清理及特殊格式处理。
- 内容与格式测试：中英文对象替换、图片和矢量编辑、失败事务、Office 内部关系、长文字完整性、公式形文字按纯文本保存、恶意外部实体及超限输入。
- WPF 测试：在隐藏的测试实例中检查选中、移动、删除、撤销、预览、文字编辑及转换，并检查 V2 的五个页签能否加载、布局不重叠；JSON 模型生成/互转/结构统计、编码页签的 Base32 往返/进制/文本统计、对比页签的目录模式与行内差异、PDF 工具的文档信息/提取文字/拆分都会实际跑一遍并核对源文件哈希不变；不自动操作用户桌面。
- 使用独立 PDFium 渲染比对合并前后和旋转后的页面像素，同时监听 .NET HTTP、Socket、DNS 事件。这个验证只覆盖测试路径，不能替代操作系统级全流量审计。
- 生成测试界面与页面 PNG 到新建的 `artifacts/verification-*` 目录。所有样例为合成文件，没有读取用户 PDF。
- 发布后对 `dist/LocalPdf` 和 `dist/LocalPdfV2` 分别执行 `--verify-local-startup`：确认 .NET 与 WPF 均从随附目录加载，检查图标、主界面和合成 PDF 解析/渲染；无可见窗口、无用户文档和输出日志。

## 项目结构

| 目录 | 职责 |
|---|---|
| `src/CRTVUP.Unify.LocalPdf.Abstractions` | 模型、异常和处理接口 |
| `src/CRTVUP.Unify.LocalPdf.Implement` | 本地 PDF 内容编辑、页面处理、Office ZIP/XML 转换和路径策略 |
| `src/CRTVUP.Unify.LocalPdf.Desktop` | WPF 内容编辑/转换界面、预览和 Windows 图片编码 |
| `src/CRTVUP.Unify.LocalPdf.DesktopV2` | V2 工具箱主窗口与五个页签（PDF / JSON / 编码 / 对比 / 压缩） |
| `assets`、`scripts/create_logo.py` | 本地几何图形绘制的原创 PDF 标志与多尺寸 EXE 图标 |
| `tests` | 核心与界面验证 |
| `vendor` | 已有本地依赖的副本、哈希和完整第三方许可 |
| `docs/PDFgear安全检查.md` | 指定 PDFgear 2.1.20 安装目录的静态审计证据 |
| `dist/LocalPdf`、`dist/LocalPdfV2` | 各自包含 runtime 的可直接双击运行文件夹 |

未修改现有 Deepdoc 项目或 PDFgear 安装目录。
